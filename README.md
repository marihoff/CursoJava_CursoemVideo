# ☕ Java — Curso em Vídeo

Repositório com os estudos do curso de Java do [Curso em Vídeo](https://www.cursoemvideo.com/), ministrado pelo professor Gustavo Guanabara.

Cada pasta representa uma aula com exemplos funcionais e bem comentados em português.

---

## 📂 Estrutura do Repositório

```
src/
├── aula01_HelloWorld/        → Primeiro programa, estrutura de uma classe Java
├── aula02_TiposEVariaveis/   → Tipos primitivos, Wrapper Classes e typecast
├── aula03_SaidaDeDados/      → print, println, printf e caracteres de escape
├── aula04_EntradaDeDados/    → Scanner, leitura de int, float e String
├── aula05_OperadoresMath/    → Operadores aritméticos e Classe Math
├── aula06_Condicionais/      → if, else, encadeadas e operador ternário
├── aula07_Repeticao/         → while, do-while, for, break e continue
└── aula08_Vetores/           → Arrays (declaração, acesso, iteração)
```

## ▶️ Como Executar

### Pré-requisitos
- [Java JDK 17+](https://www.oracle.com/java/technologies/downloads/) instalado
- Uma IDE como [IntelliJ IDEA](https://www.jetbrains.com/idea/) ou [VS Code](https://code.visualstudio.com/)

### Pelo terminal

```bash
# Compile um arquivo
javac src/aula01_HelloWorld/HelloWorld.java -d out/

# Execute
java -cp out HelloWorld
```

### Pela IDE
Abra a pasta `src/` no IntelliJ IDEA ou VS Code e execute diretamente clicando no botão ▶️ ao lado do método `main`.
